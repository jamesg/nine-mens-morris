# Jogo do Moinho (Nine Men's Morris)

Jogo de tabuleiro clássico feito em JavaScript, para dois jogadores.

## Como jogar
1. Cada jogador começa com 9 peças.
2. Na primeira fase, os jogadores se alternam colocando peças nos pontos do tabuleiro.
3. Na segunda fase, as peças são movidas para pontos vizinhos.
4. Quando alguém forma uma linha de 3 peças (um "moinho"), remove uma peça do adversário.
5. Perde quem ficar com apenas 2 peças ou sem movimentos.

## Como executar
Abra o arquivo `index.html` no navegador.

## Arquivos
- `index.html`: a página do jogo
- `nmm.js`: a lógica do jogo
